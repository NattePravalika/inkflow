# 📝 BlogVerse – Online Blogging & Article Sharing System

A full-stack web application built with **Flask (Python)**, **Bootstrap 5**, **jQuery**, and **SQLite** that allows users to register, log in, write articles, share them publicly, and engage via comments.

---

## 🚀 Features

- **User Authentication** – Register, Login, Logout with session management
- **Write & Publish** – Create rich articles with category selection
- **Edit & Delete** – Authors can manage their own articles
- **Comments** – Logged-in users can comment on any article
- **Category Filter** – Browse articles by topic
- **Live Search** – jQuery-powered client-side article search
- **Dashboard** – Personal dashboard with article stats and management table
- **Form Validation** – Client-side (jQuery) + server-side (Flask) validation
- **ML Module** – Keyword extraction & readability scoring (`model/predict.py`)
- **Responsive Design** – Bootstrap 5 grid, works on mobile/tablet/desktop

## ⚙️ Setup Instructions

### 1. Clone the Repository
```bash
git clone https://github.com/YOUR_USERNAME/blogverse.git
cd blogverse
```

### 2. Create a Virtual Environment
```bash
python3 -m venv venv
source venv/bin/activate        # Linux / macOS
venv\Scripts\activate           # Windows
```

### 3. Install Dependencies
```bash
pip install -r requirements.txt
```

### 4. Run the Application
```bash
python app.py
```

The app will start at **http://127.0.0.1:5000**

### 5. (Optional) Train the ML Model
```bash
python model/train_model.py
```

## 🌐 Flask Routes

| Route | Method | Description |
|-------|--------|-------------|
| `/` | GET | Home page – latest articles |
| `/register` | GET, POST | User registration |
| `/login` | GET, POST | User login |
| `/logout` | GET | Logout and clear session |
| `/article/new` | GET, POST | Create a new article |
| `/article/<id>` | GET | View single article + comments |
| `/article/<id>/edit` | GET, POST | Edit an article (author only) |
| `/article/<id>/delete` | POST | Delete an article (author only) |
| `/article/<id>/comment` | POST | Post a comment |
| `/dashboard` | GET | Author's personal dashboard |
| `/category/<n>` | GET | Articles filtered by category |
| `/success` | GET | Post-publish success page |
| `/submit` | POST | Generic form submit handler |

## 🖥️ Screenshots / Demo Steps

1. Open http://127.0.0.1:5000
2. Click **Join Free** → fill the registration form
3. Log in with your credentials
4. Click **Write** in the navbar → fill the article form → **Publish**
5. View your article on the home page → click to read
6. Leave a comment at the bottom of the article
7. Visit **Dashboard** to see all your articles with edit/delete options
8. Browse articles by category using the sidebar tags
